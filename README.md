## Про проєкт

**Task Manager** — це навчальний проєкт, що демонструє побудову десктопного застосунку на чистому Python без зовнішніх залежностей. Застосунок дозволяє керувати списком завдань: додавати, видаляти, позначати як виконані та призначати пріоритети.

Проєкт розділений на два шари:
- **`task_logic.py`** — чиста бізнес-логіка без UI (легко тестується)
- **`task_manager.py`** — графічний інтерфейс на Tkinter

## Скриншоти

> Нижче наведено ASCII-схему інтерфейсу застосунку (tkinter-вікно):

```
┌─────────────────── Менеджер завдань ───────────────────┐
│                                                         │
│  Завдання:  [_________________________ ]               │
│  Пріоритет: ◉ Низький  ○ Середній  ○ Високий           │
│                                                         │
│  [ Додати ]   [ Виконано ]   [ Видалити ]               │
│                                                         │
│ ┌─────────────────────────────────────────────────┐    │
│ │ [Високий]  ✓  Написати звіт                     │ ▲  │
│ │ [Середній] ○  Зателефонувати лікарю             │    │
│ │ [Низький]  ○  Купити продукти                   │ ▼  │
│ └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

### Формат елементів списку

Кожне завдання відображається у форматі:

```
[Пріоритет]  статус  Текст завдання
```

| Символ | Значення |
|--------|----------|
| `✓` | Завдання виконано (сірий колір) |
| `○` | Завдання не виконано |

## Функціональність

### ✅ Реалізовано

- **Додавання завдань** з вибором пріоритету (Низький / Середній / Високий)
- **Позначення виконання** — перемикає статус `done` при повторному натисканні
- **Видалення завдань** — підтримує множинний вибір (`Ctrl+Click`, `Shift+Click`)
- **Збереження даних** — автоматичне збереження у файл `tasks.json` з підтримкою кирилиці
- **Прокрутка списку** — вертикальний скролбар для довгих списків
- **Валідація введення** — відхилення порожніх і пробільних рядків

## Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/besssty/PRACTICE_task_manager.git
cd PRACTICE_task_manager
```

### 2. Перевірка Python

```bash
python --version
# Python 3.8.x або вище
```

### 3. Запуск застосунку

```bash
python task_manager.py
```

### 4. (Linux) Встановлення tkinter, якщо він відсутній

```bash
# Ubuntu / Debian
sudo apt-get install python3-tk

# Fedora
sudo dnf install python3-tkinter
```

> **Windows та macOS:** tkinter включено за замовчуванням у стандартний дистрибутив Python.

## Тестування

Проєкт містить два набори тестів.

### Запуск через unittest

```bash
python -m unittest test_task_logic -v
```

Очікуваний результат:

```
test_cyrillic_preserved ... ok
test_empty_text_returns_none ... ok
test_save_and_load_roundtrip ... ok
...
Ran 12 tests in 0.036s
OK
```

### Запуск через pytest

```bash
pytest test_pytest_style.py -v
```

Тести охоплюють:

| Категорія | Опис |
|-----------|------|
| `@fixture` | Повторне використання тестових даних |
| `@mark.parametrize` | Перевірка кількох наборів вхідних даних |
| `pytest.raises` | Очікувані винятки (`IndexError`, `TypeError`) |
| `@mark.skip` | Пропуск тестів для ненаписаного функціоналу |
| `@mark.xfail` | Очікувані провали (незапланований функціонал) |

### Структура тестованої логіки

```python
# task_logic.py — функції, що покриваються тестами
create_task(text, priority)          # створення завдання
delete_tasks_by_indices(tasks, idx)  # видалення за індексами
toggle_done(tasks, index)            # перемикання статусу
format_task_label(task)              # форматування рядка
save_tasks(tasks, filepath)          # збереження у JSON
load_tasks(filepath)                 # завантаження з JSON
```

## Відомі проблеми

> Нижче перераховані відомі функціональні та UI/UX проблеми, задокументовані в коді.

### Функціональні помилки

| # | Файл | Опис |
|---|------|------|
| 1 | `task_manager.py` | `save_tasks` не передавав `ensure_ascii=False` — кирилиця зберігалась як `\uXXXX` (**виправлено у `task_logic.py`**) |
| 2 | `task_manager.py` | Перевірка `if text == ""` не відловлювала рядки з пробілів (**виправлено: `not text.strip()`**) |
| 3 | `task_manager.py` | При видаленні кількох елементів цикл йшов у прямому порядку — індекси зсувались (**виправлено: `reversed(selected)`**) |

### UI/UX проблеми

| # | Опис |
|---|------|
| 1 | Фіксований розмір вікна `400×300` без можливості зміни |
| 2 | Радіокнопки пріоритету відображались без відступів |
| 3 | Кнопка «Видалити» візуально не виділялась серед інших |
